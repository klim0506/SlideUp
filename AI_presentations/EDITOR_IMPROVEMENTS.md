# Улучшения страницы редактирования презентации

> Текущий снимок редактора для справки:
> - Файл: `frontend/src/pages/PresentationView.jsx` (~4300 строк, один монолитный файл)
> - Компоненты: `SlideCanvas`, `SlideFilmstripSidebar`, `DeckAiComposer`, `EditorDesignPanel` и др. — всё в том же файле

---

## A. Стиль и визуал

### A1. Drag & drop сортировка слайдов в филмстрипе
Сейчас слайды в боковой панели можно только кликать. Добавить перетаскивание для смены порядка (библиотека `@dnd-kit/core`). Визуальная обратная связь: тень + placeholder при перетаскивании.

### A2. Анимация переходов между слайдами
При переключении слайдов — плавный crossfade или slide-in (CSS transition 200ms). Сейчас контент меняется мгновенно, что резковато.

### A3. Панель инструментов над слайдом (toolbar)
Компактная горизонтальная панель между заголовком и канвасом:
`[← Пред.] [1 / 6] [След. →]  |  [🔍 Zoom −/+]  |  [📐 Полноэкран]`
Сейчас навигация только через клики по филмстрипу или стрелки клавиатуры — нет визуального индикатора.

### A4. Тёмная тема для самого редактора
Класс `editor-dark` уже задан, но фактически редактор всегда светлый. Добавить реальный dark mode с переключателем в шапке. CSS-переменные уже используются (`--bg`, `--ink`), нужно лишь задать альтернативный набор.

### A5. Скелетоны загрузки
При первой загрузке показывать skeleton вместо одного лого + текста «Загружаем презентацию». Skeleton для филмстрипа (3 прямоугольника) + основной канвас (один 16:9 прямоугольник).

### A6. Улучшить адаптив для мобильных
Сейчас `minWidth: 320` у AI-sidebar и фиксированная сетка. На экранах < 768px: скрыть sidebar, показать кнопку «ИИ» для открытия в bottom sheet; филмстрип — горизонтальная полоска внизу.

## B. Функциональность

### B1. Удаление и дублирование слайда
В контекстном меню (ПКМ или кнопка «⋮» на слайде в филмстрипе):
- **Дублировать** — копия с новым `_sid` добавляется после текущего
- **Удалить** — с подтверждением, если слайдов > 1

Сейчас дублирование есть только через историю версий, а удаления нет вообще.

### B2. Undo / Redo (Ctrl+Z / Ctrl+Shift+Z)
Локальный стек последних 20 действий (изменение текста, перестановка слайдов, смена темы). Сейчас единственный откат — через историю версий, что неудобно для мелких правок.

### B3. Переупорядочивание буллетов внутри слайда
В inline-edit режиме — перетаскивание пунктов списка (drag handle слева от каждого буллета). Сейчас можно только редактировать текст, но не менять порядок.

### B4. Заметки докладчика (speaker notes)
Поле под канвасом (collapsible) для заметок к каждому слайду. Сохранять в `slide.notes`. Экспортировать в PPTX notes и показывать в режиме «Демо» (presenter view).

### B5. Быстрое добавление слайда без ИИ
Кнопка «+ Пустой слайд» рядом с «+ Слайд (ИИ)» в филмстрипе. Создаёт слайд с типом `content`, пустым `title` и пустыми `bullets` — пользователь заполняет вручную.

### B6. Inline-редактирование подзаголовка и контента
Сейчас `contentEditable` работает только для `title` и `bullets`. Добавить inline-edit для `subtitle` и `content` (например, текстовый блок в слайде типа `quote`).

### B7. Горячие клавиши с подсказкой
Показывать tooltip при наведении на кнопки (`Ctrl+Z` — Отменить, `Ctrl+S` — Сохранить, `←/→` — слайды, `F` — полноэкран). Добавить `Ctrl+S` для принудительного сохранения (сейчас persist — только debounce 800ms).

### B8. Индикатор сохранения
Маленький значок в шапке: «Сохранено ✓» / «Сохраняю…» / «Ошибка ✗». Сейчас `notice` показывается как текстовый блок и быстро теряется.

### B9. Выделение текста цветом / жирный / курсив
Мини-toolbar при выделении текста на канвасе: **B** / *I* / цвет акцента. Сейчас весь текст plain, нет форматирования.

## C. Рефакторинг (не видим пользователю, но ускорит разработку)

### C1. Разбить `PresentationView.jsx` на модули
Файл 4300+ строк. Выделить:
- `EditorToolbar.tsx`
- `SlideCanvas.tsx`
- `SlideFilmstripSidebar.tsx`
- `DeckAiComposer.tsx`
- `EditorDesignPanel.tsx`
- `hooks/usePresentation.ts`
- `hooks/useSlideHistory.ts`

### C2. Перевести на TypeScript
Все файлы редактора — `.jsx`. Типизировать хотя бы Slide, Presentation, Preset интерфейсы. Это предотвратит баги при изменении JSON-структуры слайдов.

### C3. Заменить inline-стили на CSS-модули или Tailwind
Сотни строк `style={{ ... }}` усложняют чтение и не дают псевдо-классов (:hover, :focus-visible, @media). Tailwind уже подключён в проекте, но в редакторе не используется.
