# Billing and pricing recommendations

Date: 2026-05-19

## Current model to keep

- Guest: 7 generated slides per month/session.
- Free: 30 slides per month, short decks, one PDF export.
- Student: 150 slides per month, all ready-made styles, unlimited PDF/PPTX, no watermark.
- Pro: unlimited slides, custom themes, public links, business-grade usage.
- Extra slide packs: only offered when the user is blocked by an insufficient slide balance; purchased slides remain until spent.

## Recommendations

- Keep one credit equal to one AI-created slide. It is easy to understand and matches user value.
- Do not promote extra slide packs on the usage/pricing page. They should feel like a rescue option, not the main product.
- Consider raising Student to 200 slides/month if education users often create 10-15 slide decks; 150 is fine for launch, but tight for weekly use.
- Consider making Free max deck size 7 or 8 consistently across UI and backend. The current guest limit is 7; Free max is 8, which is acceptable but should be named intentionally.
- Keep Pro unlimited for now. If abuse appears, use fair-use monitoring internally rather than marketing a hard cap.
- Annual pricing should remain the default highlighted choice because the product benefits from retained project history and repeat use.

## Copy guidance

- Sell subscriptions everywhere except the exact moment a user lacks slides for a generation.
- Sell Student for style/PDF/watermark/regular-work moments.
- Sell Pro for custom theme, public link, client/business sharing, and unlimited generation moments.
- In insufficient-credit moments, lead with the requested task: “Need N slides, M available”, then offer reduce, subscribe, or one-off pack.
